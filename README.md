# AYQYN — локальный прокторинг с проверкой человеком

> **Версия 0.2:** локальный CV переведён на официальные ONNX Runtime Web и MediaPipe WebAssembly в отдельном изолированном процессе Electron. Python и заблокированные Polars/Contourpy в приложении не используются. Реальный инференс и запуск собранного Windows-приложения без Python проверены на этом компьютере. [Проверки и точные границы](docs/RUNTIME_WASM.md). Полноценная проверка на чистой ОС и реальном экзаменационном видео ещё требуется.


Новый прототип для **Qostanai AI Industry Hackathon 2026, Case 3**. Рабочее название, без утверждённого названия команды. Обработка камеры на CPU этого устройства; интернет после установки и загрузки моделей не требуется.

**Статус 0.2:** рабочий вертикальный срез и Windows-пакет. 27 Node-проверок, 7 browser E2E, 10 native Electron E2E, 3 проверки отмены отложенного экзамена и 5 проверок пакета. Native E2E использовал только file-backed virtual camera: реальный CV, калибровка, экзамен, app-Ctrl+C, review/recovery, освобождение камеры, crash/reconnect и аварийный выход. Системные клавиши не блокируются. Физическая камера не проверялась. Подробные ограничения — в docs/CHECKPOINT.md.

## Быстрый просмотр без камеры

```sh
node scripts/serve.mjs
```

Откройте `http://127.0.0.1:4173` → **Открыть пример** → выберите событие → укажите причину → подтвердите/отклоните → экспортируйте JSON. Это реальные сохранённые результаты моделей на повторяемых тестовых фотографиях, а не живой экзамен. Веб-версия не включает камеру и не запускает CV.

## Локальная установка

Готовая Windows-папка: запустите AYQYN.exe. Камера выключена до согласия участника. Приложение содержит все модели и WASM; Python не нужен.

Из исходников нужны Node **24** и pnpm **11**. Первичная бесплатная установка требует интернет:

~~~powershell
./scripts/setup.ps1
pnpm start
~~~

После установки приложение работает локально без скачивания моделей. Хеши всех компонентов проверяются до загрузки. Исторические Python-скрипты оставлены для происхождения старых измерений; текущий runtime их не вызывает. Не запускайте старую Python-сборку с зависимостями Polars/Contourpy.

## Что реализовано

Экзаменатор задаёт задержки и хранение → участник соглашается на обработку → предпросмотр и медианная калибровка → локальный экзамен → события с временем, параметрами и необязательными локальными кадрами → человек принимает решение с причиной → JSON без сырых изображений.

Наблюдения: телефон в кадре; положение телефона в верхней части кадра (proxy положения в кадре); отсутствие/второе лицо; отклонение головы/iris относительно калибровки; качество кадра; попытки app-copy/navigation; потеря фокуса. Нет идентификации, распознавания эмоций, микрофона, автоматических оценок или санкций.

**Alt+Tab, Win, PrtScn и другие приложения остаются функциями ОС.** Electron запрещает переходы и новые окна внутри приложения. Для OS enforcement нужна отдельно настроенная поддерживаемая управляемая Windows-среда. Она не устанавливается и не активируется прототипом.

## Проверка

```sh
pnpm test
pnpm test:ui
node scripts/audit-wasm.mjs
node scripts/audit-wasm-parity.mjs
node scripts/audit-desktop.mjs
```

Для UI-аудита предварительно запустите `node scripts/serve.mjs`. E2E desktop использует **только file-backed virtual camera**, не физическую камеру. Первоначальный sandboxed запуск упал с `0xC0000005` до окна приложения. Изолированный запуск с task-local userData, software rendering и разрешённым запуском процесса прошёл все 10 проверок. Причина падения не подтверждена fault-module данными; это не доказательство дефекта RAM. Не повторяйте падения в цикле. `evidence/` содержит снимки, результаты и пример отчёта. `docs/ARCHITECTURE.md` содержит матрицу кейса и границ.

CV smoke set не является валидацией точности на экзаменах. Коррелированные повторения кадров не увеличивают число независимых примеров. Пропуски детектора сохраняются в результатах. Требуются добровольные реальные видео, очки, наклоны головы, небольшие устройства, похожие предметы и независимая разметка событий до пилота.

## Данные и лицензии

Журнал desktop хранится в userData приложения; тесты — в task-local `data/`. Браузерный пример хранит только состояние этого браузера. Хранение по умолчанию 24 часа; очистка при следующем открытии. Можно удалить вручную. Снимки выключены по умолчанию, отдельное согласие обязательно. ОС-пользователь/администратор с доступом к файлам может изменить журнал — криптографического доверия к этому прототипу нет.

Исходный код AYQYN и YOLO: **AGPL-3.0-only**. MediaPipe: Apache-2.0. Атрибуция изображений и условия отдельных файлов: `web/fixtures/attribution.json`; преобразованный `phone-desk.jpg` сохраняет CC-BY-SA-4.0. Другие тестовые изображения: CC0/NASA public domain. Данные не означают одобрения проекта авторами или людьми на фото. Источники PDF кейса не включены.

AI assistance: код, интерфейс, документы и тесты созданы при помощи Codex по требованиям капитана; публичные модели не обучались командой. Команда должна проверить код и уметь объяснить worker, thresholds, calibration, privacy и OS boundary. Репозиторий и CI ещё не опубликованы в этом checkpoint.
